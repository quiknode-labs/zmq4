`zmq4` is a pure-Go implementation of ØMQ (ZeroMQ), version 4.

This repository is a fork of [`github.com/go-zeromq/zmq4`](https://github.com/go-zeromq/zmq4), maintained by [Quicknode](https://www.quicknode.com).

See [zeromq.org](https://zeromq.org) for more information.
